# Proven C Book

proven C 라이브러리에 기반한 모던 C 프로그래밍 입문서. 저자 rubidus.

프로그래밍을 처음 배우는 독자를 출발점으로, 전산학과 컴퓨터 사이언스의
기본 개념부터 시작하여 최신 C 표준(C23)과 현대적 C의 흐름까지 다루는
책을 저술하는 프로젝트다. 기존 C 입문서의 목차를 답습하지 않는 새로운
구성과 체계를 목표로 하며, 최신 교수이론(학습과학)에 근거한 서술 —
즉각적인 질문과 답, 잦은 실제 사례, 오개념의 선제적 교정 — 을 원칙으로
삼는다.

이 저장소는 책의 원고(Typst), 수록 예제 코드(C23), 그리고 예제를 실제로
컴파일·실행 검증하는 스크립트를 담는다. 완성된 소프트웨어 제품이 아니라
저술 프로젝트다.

## Stack

- 조판/빌드: Typst → PDF
- 예제 코드: C23, proven C 라이브러리 기반
- 예제 검증: 전 예제 컴파일·실행 검사 스크립트
